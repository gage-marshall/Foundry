## What is Foundry?

Foundry Engine is a FastAPI-based web engine designed to serve static sites with a focus on security, reliability, and speed. It's built for developers who want a clean separation between their content and the engine that powers it.

### Key Features

- **Security First**: Built-in JWT authentication, CSRF protection, rate limiting, and comprehensive security headers
- **Lightning Fast**: Async/await throughout, optimized caching, and minimal dependencies
- **Configuration-Driven**: YAML for structure, Markdown for content, CSS for styling
- **Modular Design**: Extensible section types and navigation styles
- **Render-Ready**: Optimized for deployment on Render with health checks and production configs

### How It Works

1. **Define Your Structure**: Use YAML files to describe your pages and sections
2. **Write Your Content**: Use Markdown for rich text content
3. **Style Your Site**: Customize the look with CSS themes
4. **Deploy**: Push to Render and you're live

### Built-In Section Types

- **Hero**: Eye-catching hero sections with CTAs
- **Parallax**: Beautiful parallax scrolling effects
- **Gallery**: Photo galleries with multiple layouts
- **Text**: Rich markdown content
- **Contact**: Fully-featured contact forms
- **Features**: Feature grids with icons
- **CTA**: Call-to-action sections
- **Footer**: Flexible footer layouts

### Email Integration

Send contact form submissions via:
- **Brevo** (formerly Sendinblue)
- **Mailgun**
- **Generic SMTP**

### Navigation Types

- **Top Ribbon**: Classic navigation bar
- **Hamburger Menu**: Mobile-friendly hamburger menu
- **Sidebar**: Vertical sidebar navigation
